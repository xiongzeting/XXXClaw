# 记忆系统最终架构

本项目当前用于面试和实现对照的唯一简明口径见 [`docs/memory-final-upgrade.md`](../memory-final-upgrade.md)。

核心记法：

```text
入口 → 准备 → 分源召回 → 各源排序/过滤
     → 合并 → 统一重排 → 去重 → 按预算返回
```

Working Context 的压缩再记成一条短线：

```text
触发 → 安全切点 → 归档 → 摘要 → 原子提交 → 恢复
```

soft 压力只走确定性摘要，hard 压力且语义密集时才调用模型；模型摘要失败回退，取消中止，摘要膨胀则不提交。原始 JSONL 永不覆盖，`compaction` 事件是唯一提交标记。提交后只刷新一次 Memory，并独立重新匹配/加载一次 `SKILL.md`。

Procedural / `SKILL.md` 不参加这条 memory 管线；它按目录元数据匹配，在任务开始和每次已提交压缩后独立加载，引用资源按需读取。模型可见的 `memory` action 只有 `search / remember / replace / forget`。
