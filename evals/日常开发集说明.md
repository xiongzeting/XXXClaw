# 日常开发集 v1

入口：`development-everyday-v1.json`。三种任务族：CSV 库与命令行接口、跨文件配置解析、过滤排序与分页。输入保持日常规模，不要求人为压缩次数，不要求模型向外部 oracle 填特殊验收 JSON。

这三题与旧六道长任务挑战题分开报告，不能混成一个“通用成功率”。当前均为开发集、已曝光；没有新建或宣称盲测保留集/测试集，也不能凭三题宣称分类覆盖充分。后续封存任务须由独立流程准备，不能用已读题换个名字冒充未见测试。

外部 oracle 保存于工作区之外，固定哈希后在无网络、只读 Docker 中运行。每族先用可信参考实现验证通过，再分别替换两种错误实现，验证判为能力失败；共九次校准。脚本：`scripts/build_everyday_eval_v1.py`，结果：`.aster/evals/everyday-v1-calibration.json`。未执行模型，尚无能力或效率成绩。

本批只补交付行为的任务分布。原有五维挑战回归保持不变；不把此处 outcome 校准称为安全、过程或可用性已通过。80,000 tokens / 40 次工具调用为新日常集预先设置的工程预算，不用于修改旧挑战题阈值。
